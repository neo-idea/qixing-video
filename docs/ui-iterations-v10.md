# 七星视频 UI 自迭代 V10

## 版本清单

1. **V1 移动端信息架构**：移除头部第二套分类条，移动端分类仅保留底部导航。
2. **V2 首屏影院感**：推荐轮播支持悬停暂停、后台停转、语义化与主图分级加载。
3. **V3 海报加载质感**：修复切图失败状态残留，加入异步解码与模糊显现。
4. **V4 分类浏览效率**：筛选条件吸顶，显示已选数量并支持一键重置。
5. **V5 搜索体验**：新增本机搜索历史，支持回填与清空。
6. **V6 搜索排序**：按相关度与评分稳定排序，来源分组按命中质量排列。
7. **V7 智能换源**：同名来源可播优先，并标记可播 / 受限状态。
8. **V8 播放连续性**：记忆本机播放进度，自动续播并给出提示。
9. **V9 接口源管理**：站点源支持关键词过滤，多配置下可快速定位。
10. **V10 全局收口**：底部导航状态实时同步，页脚信息架构与品牌描述统一。

## 后续增强

- **V11 源级动态分类**：头部导航、底部快捷分类与首页片库共用当前源的 `homeContent.class`；请求按“配置地址 + 站点 key”缓存去重，切换源时旧分类立即失效，避免展示上一个源的结构。
- **V12 STREAM-LIB 线路库**：支持 `urls` 线路库一键导入与逐条体检；含 Web 可播源的线路自动启用，失效 / 受限线路保留关闭并展示原因、站点数与可播数。配置体检结果写入服务端 TTL 缓存，避免导入后合并阶段重复下载。
